# Uptime Monitor

Self-hosted website and API uptime monitoring platform.

## Tech Stack

- Python
- FastAPI
- PostgreSQL
- Docker
- Docker Compose

## Features

- HTTP endpoint monitoring
- Response time tracking
- Uptime statistics
- Telegram notifications

## Development

Run locally:

docker compose up -d --build

API:
http://localhost:8000

API Documentation:
http://localhost:8000/docs
